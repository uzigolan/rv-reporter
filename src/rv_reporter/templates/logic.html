Start

Entry point for the New Type workflow map.

Trigger
User submits the New Type form — with or without a source file attached.
Input
HTTP POST to /report-types/new. Optional file upload, prompt text, domain / family / mode hints.
Entry point Not an agent

Sample guardrail

Rule-based preflight checks on the uploaded source file.

Type
Code — no AI. Calls preflight_tabular_source() in services/ingest.py.
Trigger
Runs immediately after Start when a source file is present. Skipped if no file was attached.
Checks
File parses cleanly · has tabular structure · no repeated headers · no metadata leakage · non-zero row count
Output
Pass → continue to Classification agent. Fail → route to End (blocked) with issue list.
Code · no AI services/ingest.py

Classification agent

Determines the user's next action in the authoring journey.

Trigger
After guardrail passes. Also re-runs when the user saves edits in the Review & Edit step and re-submits.
Output
Returns an intent string: one of upload_sample, write_prompt, or preview_and_review.
Agent OpenAI Responses API

API call parameters

Endpoint
client.responses.create()
Model
gpt-4o (default) · configurable via REPORT_TYPE_AGENT_MODEL env var
Instructions (system)
"You are drafting a new report type for a schema-first reporting system. Return a JSON object only. Choose family, domain, and mode from the allowed sets…"
Input payload
{ prompt, clone_from, clone_yaml, existing_report_types, allowed_families, allowed_domains, allowed_modes, source_profile, classification_hints }
Response format
json_schema · schema name: report_type_agent_draft · strict: false
Auth
OPENAI_API_KEY env var (required)

Condition

Routes the flow based on the intent string from the Classification agent.

Type
Code — Python switch on the intent field. No AI involved.
Routing rules
upload_sample → Sample Source
write_prompt → Prompt writer
preview_and_review → Review + preview
Else → End (blocked)
Code · routing Not an agent

Sample Source

Captures the example data file for the new report type.

Type
Form handler (no AI) — saves the uploaded file to uploads/ and stores the path in the session.
Trigger
Reached when intent == "upload_sample". User attaches a CSV, Excel (.xlsx/.xls), or PCAP file.
Output
File path stored in session. Column list extracted via pandas. Form loops back to Classification agent for the next intent decision.
Code · file ingest Not an agent CSV · Excel · PCAP

Prompt writer

Generates the full report type YAML, plugin, and smoke tests via AI.

Trigger
Reached when intent == "write_prompt". Receives the prompt text plus the column profile from the sample source.
Output
Draft files written to report_type_plugins/<id>/: YAML config, plugin.py, manifest.yaml, and test_smoke.py. Redirects to Review & Edit step.
Agent OpenAI Responses API YAML · plugin · tests

API call parameters

Endpoint
client.responses.create()
Model
gpt-4o (default) · configurable via REPORT_TYPE_AGENT_MODEL env var
Instructions (system)
"You are drafting a new report type… Choose family, domain, mode from allowed sets. Generate plugin.py with get_spec() and build(df, prefs, ctx). Generate smoke_test_code as a pytest file…"
Input payload
{ prompt, clone_from, clone_yaml, existing_report_types, allowed_families, allowed_domains, allowed_modes, source_profile, classification_hints }
Response format
json_schema · schema name: report_type_agent_draft · strict: false
Response schema fields
report_type_id, title, family, domain, mode, description, required_columns, default_prefs, prompt_instructions, plugin_code, smoke_test_code, manifest_extensions
Auth
OPENAI_API_KEY env var (required)

Review + preview

Runs the full report pipeline against the sample source — no API cost.

Type
Code — calls run_pipeline() with MockProvider. Deterministic local metrics. No AI callout.
Model
MockProvider (local) — uses the plugin's build() function directly. Zero token cost.
Trigger
Reached when intent == "preview_and_review". The draft plugin files must already exist.
Pipeline steps
Ingest → Profile → Metrics (plugin) → MockProvider → Validate schema → Render HTML + JSON artifacts
Code · local pipeline MockProvider No AI cost

User approval

Human decision checkpoint after the preview report is shown.

Type
Human decision — the user reviews the rendered HTML report and chooses to publish or iterate.
Trigger
After the preview report is rendered and the result page is shown.
Approve path
Click Publish Report Type → manifest set to active → type appears in Generate menu.
Reject path
Edit YAML / plugin in the Review & Edit step → re-submit → flow loops back through the Condition block.
Human Not an agent

Blocked end

Early termination — source failed guardrail checks or condition had no matching branch.

Trigger
Guardrail returns issues (unparseable file, missing columns, repeated headers) — or Condition receives an unrecognised intent value.
Result
Authoring flow terminates. User is shown the issue list and can fix the source file or adjust the prompt before resubmitting.
Terminal · blocked Not an agent

Published end

Report type is now active and available in the Generate menu.

Trigger
User clicks Publish Report Type on the Review & Edit page. Smoke test runs automatically before activation.
Result
Manifest status set to active. Type is registered in plugin discovery. Future runs use the standard Generate path — this authoring canvas is no longer needed.
Terminal · published Not an agent
